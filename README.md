# Student Database Application System – Backend

A modular backend application built with **FastAPI** for managing student records through RESTful APIs, with **SQLite + SQLAlchemy ORM** for database operations and an integrated **Google Gemini AI assistant powered through LangChain** for answering natural-language questions about student statistics.

> **Project Note:** The frontend included in this repository is a lightweight demo client used to visually test and interact with the backend APIs. The core deliverable of this project is the backend service.

---

## 🚀 Features

* RESTful APIs using FastAPI
* Student CRUD operations
* SQLite database
* SQLAlchemy ORM
* Pydantic request/response validation
* Duplicate email protection
* Proper HTTP status codes and error handling
* Swagger/OpenAPI documentation
* CORS configuration for frontend integration
* Google Gemini AI integration
* LangChain-based chatbot service
* Natural-language student statistics queries
* Controlled AI access to database statistics
* Automated API tests with Pytest
* Modular project architecture
* Simple frontend demo client

### AI Chat Flow

The chatbot does not directly execute arbitrary SQL queries generated by the AI.

Instead:

```text
User Question
      ↓
FastAPI /chat endpoint
      ↓
Chat Service
      ↓
Controlled Student Statistics
      ↓
LangChain
      ↓
Google Gemini
      ↓
Natural-language Answer
```

This keeps database access controlled by the backend application.

## 📌 API Endpoints

| Method | Endpoint                 | Description                     |
| ------ | ------------------------ | ------------------------------- |
| GET    | `/`                      | Backend health/message endpoint |
| POST   | `/students`              | Create a student                |
| GET    | `/students`              | Retrieve all students           |
| GET    | `/students/{student_id}` | Retrieve a student by ID        |
| PUT    | `/students/{student_id}` | Update a student                |
| DELETE | `/students/{student_id}` | Delete a student                |
| POST   | `/chat`                  | Ask the AI assistant a question |

## 🤖 AI Assistant

The `/chat` endpoint allows users to ask natural-language questions about available student statistics.

### Example Questions

```text
How many total students are there?

How many are male and female?
```

The backend calculates the available statistics from the database and provides the relevant information to the Gemini-powered assistant.

The AI assistant is instructed not to invent student information or answer questions beyond the statistics currently made available to it.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Mohd-Shariq-codes/Student-Database-Application-System-Backend.git

cd Student-Database-Application-System-Backend
```

### 2. Create a virtual environment

```powershell
py -3.13 -m venv venv
```

### 3. Activate the virtual environment

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

---

## 🔐 Environment Variables

Create a `.env` file in the project root:

```env
APP_NAME=Student Database Application System
DATABASE_URL=sqlite:///./students.db
GEMINI_API_KEY=your_gemini_api_key_here
```

Replace the placeholder with your own Gemini API key.

**Never commit the `.env` file to GitHub.**
